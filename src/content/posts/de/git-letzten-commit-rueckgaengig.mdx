---
title: 'Git: Letzten Commit rückgängig machen'
description: 'Den letzten Commit zurücknehmen, ohne die Änderungen zu verlieren.'
pubDate: 2026-11-10
tags: ['git']
categories: []
sections: ['code']
---

Wenn der letzte Commit noch nicht gepusht ist, geht das mit einem Soft-Reset. Die Änderungen bleiben im Arbeitsverzeichnis erhalten.

```bash
git reset --soft HEAD~1
```

Sollen die Änderungen auch aus dem Index verschwinden, aber in den Dateien bleiben, nimmst du `--mixed` (der Standard).
